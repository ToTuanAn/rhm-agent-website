Abstract

Long-form video understanding remains challenging for VLMs due to the cost of processing extensive frame sequences and the limited ability of flat or heuristic memory structures to support efficient retrieval and long-horizon reasoning. To address these challenges, we introduce Reinforced Hierarchical Memory Agent (RHM-Agent), which organizes visual evidence into hierarchical memory to selectively retrieve relevant cues and construct explainable, intelligent, and non-linear reasoning paths. Equipped with dynamic memory, the RHM-Agent is optimized via a hierarchical reward mechanism to balance local details with global context, enabling it to navigate long videos in a human-like manner. To evaluate long-horizon temporal reasoning and memory efficiency beyond standard accuracy, we propose HMBench-2K, a long-form egocentric video benchmark spanning four domains: medical, industrial, marine, and autonomous driving. Additionally, we introduce two complementary diagnostic metrics, frame brevity and node precision, to assess evidence efficiency and temporal precision, respectively. Extensive experiments show that our RHM-Agent surpasses baselines with 4× the parameters or 2× the frames by up to 6.63% on LVBench and 5.60% on Ego4D, proving strategic memory optimization yields greater improvements than the brute-force scaling of model size or frame count. Evaluated directly on our proposed HMBench-2K, RHM-Agent outperforms SOTA VLMs and long-video agents by 2.00% and 7.15%, respectively, demonstrating effective long-form egocentric video understanding. Further analysis shows that our method not only improves accuracy in a model-agnostic design but also achieves better temporal alignment than current dynamic memory-augmented agents.

Overview

Paper summary

How RHM-Agent grows a hierarchical memory tree, how a reinforced policy learns to expand, exploit, or answer inside it. Moreover, the HMBench-2K long video question-answering benchmark is introduced to rigorously evaluate long-horizon memory agents.

Background

A dynamic hierarchy, not a fixed buffer

VideoTree grows a rigid tree via K-means, while VideoAgent and VCA maintain linear or sliding-window buffers. Their memory is constructed using heuristics or unsupervised objectives; consequently, nothing in the pipeline can be optimized end-to-end, and every decision is delegated to a large VLM backbone. RHM-Agent, however, organizes sparse visual evidence into a hierarchy that is dynamically pruned and intelligently expanded. Crucially, our entire pipeline is fully optimizable.

Method

Memory as an action space

Each iteration selects N nodes, rolls out L expansion steps, and lets the agent decide whether to expand a node, exploit it, or commit an answer — with a reward that is applied at every node instead of only at the end.

01

Hierarchical memory bank

Frames are sampled uniformly and a binary mask tracks every visited frame. An expandable node spawns two children halfway between its nearest visited neighbours, so the tree partitions the timeline instead of revisit. A maximum depth D bounds the expansion, avoid infinite loops.

02

RHM-Agent Reasoning

Instead of expanding every node, the agent ranks the current node set against the question and keeps the top N. Each selected node is then rolled out for up to L decisions including expand, exploit, or an answer leaf, dynamically adjust N and L let breadth and depth adapt to the query.

03

Local and global tree rewards

Leaf answers receive a bottom-up local reward that credits every node on the path; the root answer receives a global reward. Their sum forms the advantage in a group-relative policy optimisation step, which keeps the tree compact and the reasoning paths traceable.

Results

Stronger over long horizons

An 8B RHM-Agent with a 16-frame budget beats 8B baselines using twice the frames and 32B models using four times the parameters. Because the memory is structured rather than enlarged, the gain survives on egocentric video as well.

Against dynamic memory agents the gap widens: +12.30% average accuracy over VideoAgent and +7.15% over VCA on HMBench-2K, with higher node precision (+0.29% over VideoAgent, +0.59% over VCA) and better frame brevity than VCA. Memory depth helps only where the videos are long enough to need it — deeper trees help the 8B model on Ego4D up to depth five, but hurt smaller models on the much shorter EgoSchema clips.
